## Breif 
This is Sentimental, an AI-powered Market Insight & Sentiment Agent that converts real-time financial news into structured, explainable insights, addressing the core problem of information overload in trading where users struggle to understand what drives market movements. The system ingests live data via APIs, structures it into a knowledge base, and uses IBM watsonx Orchestrate with foundation models(GPT-OSS-120B) to analyze article relevance, extract sentiment, identify key drivers and risks, and compute confidence scores based on consistency across sources. Instead of simple summaries, the agent generates a coherent “market snapshot” that explains why stocks move, enabling more informed decision-making. This project demonstrates an agentic AI workflow data ingestion, reasoning, and synthesis and has potential to scale into portfolio monitoring, automated financial briefings, and broader risk analysis systems.
